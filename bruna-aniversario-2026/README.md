# Aniversário da Bruna ♡

Página estática criada como uma pasta independente dentro de `Hattz-Painel`; os arquivos existentes do projeto não foram substituídos.

## Publicação

Se o GitHub Pages já estiver habilitado para este repositório e publicar a branch `main` a partir da raiz, a página ficará disponível no caminho `/Hattz-Painel/bruna-aniversario-2026/` do site Pages. Se Pages não estiver habilitado, será necessário ativá-lo em Settings → Pages.

A página ainda usa espaços reservados para fotos/prints. Como o repositório é público, só adicione imagens e textos que você esteja confortável em deixar públicos.
